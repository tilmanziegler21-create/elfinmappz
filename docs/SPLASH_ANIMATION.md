# Заставка ELFIN Market

Полноэкранный старт в ледяной гамме. Техническая схема как у изученного splash: этапы, обводка кольца через `stroke-dashoffset`, предварительное декодирование кадров и уход по факту готовности. Код VENOM не копировался. Тёмный фон не используется.

Главная уже смонтирована под заставкой. Заставка не открывается при переходе между разделами и не держит отдельный вход.

## Последовательность

1. Ледяной фон и сапфировое кольцо вокруг `/elf.jpg`. Лицо не перерисовывается.
2. Портрет: opacity и scale `0.94 → 1`.
3. `ELFIN MARKET` по буквам, затем крупное `ELFIN` и строка «Пробуждаем ледяную магию».
4. Полоса — `scaleX` от измеренного прогресса.
5. Заставка держится 2,3 с и гаснет около 2,7 с. Если данные приходят позже, она остаётся до ответа.

`prefers-reduced-motion` оставляет статичный портрет, полное кольцо и ту же полосу. Декоративная пауза при этом около 160 мс.

## Прогресс

Доли: Telegram 15, конфигурация 25, сессия 20, каталог 25, критические кадры 15.

100% только когда готовы все пять. Пока нет — не выше 99. Случайного процента нет.

Статусы: «Инициализация», «Подключаем магазин», «Загружаем витрину», «Готово».

Если ответ не пришёл за 12 секунд или запрос оборвался, статус «Магазин не ответил» и кнопка «Повторить». Успех при этом не рисуется. Повтор идёт тем же запросом конфигурации и тем же входом, без второго auth.

`prewarmImages` декодирует `/elf.jpg` и до четырёх кадров витрины, не больше двух одновременно. Сломанный файл не останавливает старт. Остальные фото каталога по-прежнему грузятся позже, в простое.

Повтор в той же вкладке идёт те же 2,3 с. Разделы после ухода заставки её не вызывают.

## Проверка

Локальный API Hamburg, каталог demo, записи не в таблицу.

| Сценарий | Что видно |
| --- | --- |
| Холодный старт | Заставка на экране около 2,3 с, уход к 2,7 с. Под ней главная. |
| Повтор в сессии | Та же длительность, около 2,7 с. |
| Медленный `/api` | «Инициализация», 15%. Фиктивных 100% нет. После ответа открывается главная. |
| Обрыв API | «Магазин не ответил», кнопка «Повторить», проценты скрыты. |
| Смена раздела | После ухода заставки переход в каталог её не возвращает. |
| 320 и 430 | Горизонтального скролла страницы нет. |
| Возраст не подтверждён | После заставки остаётся прежний экран 18+. |
