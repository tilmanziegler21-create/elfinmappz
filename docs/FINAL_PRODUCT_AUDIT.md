# Финальный аудит ELFIN Market

Дата проверки: 27 октября 2026. Город интерфейса: HH / Hamburg. Публичный адрес: https://elfinmappz.onrender.com.

Это не статус готовности к продажам. Сквозной заказ в настоящем Telegram не выполнен.

## Что проверено публично

- `GET /` — 200, HTML Mini App, в разметке есть `id="root"`.
- `GET /api/health` — `ok: true`, город HH, каталог `sheets`, `writes: false`.
- `GET /api/ready` — API ready, Telegram `configured` (это только наличие переменных, не `getMe`), Sheets `ready`, база `ephemeral`, запись выключена.
- `GET /api/config` — `devAuth: false`, `liveOrders: false`, `sheetsWrites: false`.
- `GET /api/catalog?city=HH` — 104 активных товара из книги HG. Пример: ELFLIQ / Blackberry Lemon.
- `GET /api/couriers?city=HH` — 200 и пустой список. Курьера в оформлении выбрать нельзя.
- `POST /api/order/create` без сессии на уже выложенной ревизии `5f19763` отвечал 401 `Authentication required`. Значит `JWT_SECRET` на Render задан: иначе был бы 500. После этой ревизии production без постоянной базы снова отвечает 503 `ORDERS_NEED_DATABASE`. Этот ответ появится только после деплоя нового коммита.
- В браузере на публичном сайте пройдены: возраст, главная, каталог, карточка ELFLIQ, вкус, корзина, оформление, заказы без сессии, профиль без сессии. Горизонтального переполнения на ширине 320 и 390 нет. Поля оформления на выложенной версии уже 16px.

## Что не подтверждено

- `getMe` локального токена: 401 Unauthorized. Webhook не настраивался. Настоящий чат Telegram, iOS и Android не открывались.
- Постоянное хранилище. `/api/ready` показывает `database: ephemeral`. `DATABASE_URL` на сервисе не подключён. Заказ после рестарта Render не сохранится.
- Вкладки `products_HH` в подключённой книге нет. Каталог читает `*_HG` по явному предыдущему решению. Это не München: локальная книга München по-прежнему отдаёт `SHEETS_HH_MISSING`, а живой сервис читает HG.
- Рабочая таблица не изменялась.

## Исправления этой ревизии

- Подпись Telegram `initData` отклоняется, если `auth_date` нет или ему больше 24 часов.
- В production без PostgreSQL или постоянного диска создание, подтверждение и оплата заказа снова отклоняются. Временный заказ не считается продажей.
- Сообщения бота вне `NODE_ENV=test` больше не обходят `TELEGRAM_TEST_MODE`. Пока режим не равен `0`, уходит только на `TELEGRAM_TEST_IDS`.
- Локальный сервер разработки, если Google Sheets недоступен, снова берёт учебный каталог. Иначе тест перезапуска терял заказ.

## Карта, которая работает сейчас

Покупатель в браузере видит каталог HG без входа. Корзина хранится в браузере. Оформление открывается. Подтверждение на Render не создаёт постоянный заказ и не пишет склад. Бот в Telegram этим токеном не проходит `getMe`.
