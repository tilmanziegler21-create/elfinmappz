## Поля products

| Поле | В таблице | В модели |
| --- | --- | --- |
| sku | уникальный номер | id товара, корзина и склад |
| name | вкус | подпись вкуса, не заголовок бренда |
| category | ценовая группа как есть | `liquids` и `liquids1` не склеиваются |
| brand | производитель | заголовок карточки |
| price | евро | базовая цена карточки |
| stock | целое | 0 — в заказ нельзя |
| active | TRUE/FALSE, true/false | false — товар не попадает в витрину |
| image | путь картинки строки | только эта строка; чужой SKU его не получает |

Проверка `products_MU`: 131 строка, 131 уникальный SKU, ошибок нормализации нет.

| category | строк |
| --- | --- |
| liquids | 48 |
| pods | 11 |
| electronics | 72 |

`liquids1` в этой таблице нет. Для покупателя `liquids` и `liquids1` — один раздел «Жидкости». В товаре, корзине и заказе сохраняется исходная категория. Опт считается отдельно: таблица без поля категории не даёт скидку и блокирует такое оформление. Скидки не выдуманы.

Бренды раздела: HQD, ELFLIQ и VOZOL — `liquids`. CHASER FP, CHASER LUX и любой другой CHASER — `liquids1`. Фильтр бренда для всех CHASER — «CHASER».

`active = false` — 11 строк, у всех `stock = 0`. Активных с нулём нет. Неактивные в каталог не отдаются. Нулевой остаток в заказ не добавляется.

Пример, который не совпал с таблицей: HQD Black Ice в строках нет. `LQ-001` — это ELFLIC, вкус `* Apple Peach`, категория `liquids`, цена 16, остаток 0, `active = false`. В оформление он не идёт.

## Картинки

Колонка `image` заполнена у всех 131 строк. Это общие файлы бренда, например `/images/brands/elflic.png`, а не отдельная этикетка вкуса. Этих файлов в проекте нет, поэтому карточка остаётся на кристалле.

Вырезанные ELFLIQ, CHASER, HQD, VOZOL и XROS в `productMedia.json` к SKU не привязаны. Grapey не ставится на другой вкус. Зелёный XROS не ставится на PD-001 и остальные цвета.

## Цены

`LiquidPrices_MU`: колонки `city`, `qty_from`, `qty_to`, `price`. Города в строках: FFM, HG, MU. HH нет. Правила не подтверждены и к цене не применяются. На карточке остаётся `price` из строки товара. Скидки не добавлялись.

FFM и HG в каталог Hamburg не читаются.
