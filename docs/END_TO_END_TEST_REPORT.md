# Сквозные проверки

Дата: 26 октября 2026. К эксплуатации система не готова.

## Выполнено

Текстовый бот, локальная книга заказов:

- первый и повторный `/start` — один профиль;
- Mini App только на `https://`, локальный URL отклонён;
- заказы только своего пользователя, чужой `order_id` не открывается;
- профиль из переданных данных, не из выдуманной скидки;
- поддержка сохраняется, фиктивный менеджер не показывается;
- некурьер не видит чужой заказ курьера;
- «Выдал» один раз, повтор отвечает, что заказ закрыт;
- отмена чужого заказа не проходит;
- `/admin` закрыт для покупателя;
- длинный Telegram id не теряет точность;
- лимит частоты на чат;
- тексты RU, DE, EN.

Очередь уведомлений:

- без токена `sent` ложен, ошибка `NO_TOKEN`;
- тестовый режим блокирует получателя вне списка и не вызывает Telegram;
- таймаут оставляет `sent` ложным;
- успешный ответ отправляется один раз.

Заказы на локальной книге, не в Google: `fixes.test.mjs` 17/17, `chain.test.mjs`, `reliability.test.mjs` 31/31. Повторный confirm не меняет курьера. Отмена после списания возвращает остаток один раз.

Google, только чтение: вкладки HH отсутствуют, каталог HH отвечает `SHEETS_HH_MISSING`. `hh.test.mjs` прошёл с внешним ключом.

`tsc --noEmit` и production build прошли. `server/bot.test.mjs`: 24 проверки.

## Не выполнено

- `getMe` вернул `401 Unauthorized`. Бот в Telegram не запущен, `/start` живому аккаунту не отправлялся, сообщений клиентам и курьерам нет.
- `MINIAPP_PUBLIC_URL` не задан. Кнопка меню и `web_app` не ставились.
- `products_HH` нет, поэтому реальные SKU, цены и остатки Hamburg в Mini App не пришли.
- `SHEETS_TEST_SPREADSHEET_ID` нет. Создание заказа, резерв, списание, выдача и отмена в Google не запускались. Рабочая таблица не изменялась.
- Сквозной путь «клиент в Telegram → Mini App → заказ → курьер нажал Выдал → статус у клиента» не проходился. Локально этот переход статуса покрыт API-тестами.
- Самостоятельная кнопка «18+» не считается проверкой возраста. Товары для реальной продажи не активировались.

## Что остаётся сделать снаружи

Новый токен BotFather во внешнем env, если текущий Telegram отклоняет. Публичный HTTPS Mini App. Свои вкладки `*_HH` в рабочей таблице, без переименования MU. Отдельная копия таблицы для записи и явная команда включить её. До этого `TELEGRAM_POLLING` остаётся выключенным, запись в Google выключена, каталог Hamburg не подменяется демо без `DEMO_CATALOG=1`.
