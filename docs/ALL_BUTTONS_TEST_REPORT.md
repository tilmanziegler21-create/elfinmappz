# Проверка кнопок

Дата: 28 октября 2026. Локальный магазин `http://127.0.0.1:5173` на отдельной папке данных, без токена Telegram и без PostgreSQL. Живой сайт для слотов: https://elfinmappz.onrender.com. Playwright в проекте нет. Клики сделаны в браузере.

Прежние 32 клика каталога, корзины и вкладок в эту таблицу не входят: те экраны здесь заново не обходились. Ниже только закрытие прежних дыр и новые проверки. Числа считаются по этой таблице.

## Исправлено и проверено снова

Повторное подтверждение без Telegram сначала показывало «Курьер получил сообщение в Telegram» и очищало корзину. Флаг успеха ставился до проверки ответа. Теперь при `telegram: false` заказ не считается оформленным, корзина остаётся, повтор пишет ту же ошибку.

Демонстрационный каталог не запрашивал курьеров. Теперь запрос идёт и в этом режиме. На живом сайте список и раньше приходил из API.

Если при сохранении заказа сервер не ответил, оформление пишет «Заказ не удалось сохранить. Попробуйте ещё раз.» и снова принимает нажатие. Смена роли при ошибке сети показывает «Сервер не ответил.» Админ без курьерской смены видит «Эта роль не назначена курьером.»
