# ELFIN Product Motion

Светлая ледяная сцена. Движутся только `transform` и `opacity`. Фирменная графика и CSS другого магазина сюда не переносятся.

Вырезанный флакон парит отдельно от кристаллов, сияния, тени и дымки. Тень не едет вместе с товаром. Общий кристалл без фото по-прежнему наклоняется на ±3°. Прозрачный PNG с пресетом парит только на странице товара. JPEG и кадр без прозрачных пикселей остаются неподвижными (`static-product` / фото). Ошибка загрузки и пустой адрес возвращают кристалл. Каталог фото не парит.

Пресеты в `scenePresets`: `liquid-float` 5,5 с / 10 px / ±1,5°, `device-float` 6 с / 7 px / ±1°, `pod-float` 6,5 с / 6 px / ±0,8°, `static-product` без движения. Цвет подсветки задаёт `accent`, не отдельный движок. Дымка есть у ELFLIQ и VOZOL. Скрытая вкладка и `prefers-reduced-motion` останавливают парение.

## Сцена товара

`ProductFloatStage` на странице товара. У ELFLIQ поверх общей сцены есть лёгкий тёплый отсвет и нижняя дымка. Дымка сдвигается только на `transform` и `opacity`. На слабом устройстве дымка стоит, парение флакона остаётся. `prefers-reduced-motion` выключает парение, наклон, тень и дымку.

| Движение | Параметр |
| --- | --- |
| Парение | 5,5 с, ±10 px |
| Наклон | 11 с, ±3° у кристалла; у пресета свой угол |
| Тень | тот же цикл 5,5 с: `scaleX` и `opacity` |
| Вход | 700 мс, opacity и сдвиг |
| Смена кадра | 260 мс |
| Дымка ELFLIQ | 9 с, сдвиг 4 px, только opacity и transform |

| Движение | Параметр |
| --- | --- |
| Парение | 5,5 с, ±10 px |
| Наклон | 11 с, ±3° у кристалла; у пресета свой угол |
| Тень | тот же цикл 5,5 с: `scaleX` и `opacity` |
| Вход | 700 мс, opacity и сдвиг |
| Смена кадра | 260 мс |

Тень не использует постоянный blur. Поверх знака нет бегущего блика. Кристаллические слои фона остаются в сцене. На устройстве с `saveData` или двумя ядрами и меньше эти слои замирают, парение знака остаётся.

В каталоге товары не парят.

## Объём

`VariantBottomSheet` читает `product.variants`. Второй список объёмов не создаётся. Панель выезжает снизу за 380 мс. Поиск фильтрует подписи. Недоступный объём отключён. Выбор, Escape и нажатие вне панели закрывают её. Снизу учтён `safe-area-inset-bottom`.

## Мелкие действия

| Действие | Движение |
| --- | --- |
| Нажатие карточки | scale 0.97 |
| Добавление | короткий scale кнопки, текст «Добавлено» |
| Счётчик корзины | до 1,55× и поворот, один раз на изменение |
| Снятие отмеченной карточки и строки корзины | opacity и scale 0.92 |
| Нижнее меню | подложка переезжает пружиной |

Отмеченные позиции живут в `localStorage` (`elfin-saved`) и не меняют корзину. Снятие убирает карточку только из ряда «Отмеченные».

## Картинки

`preloadImages` сначала декодирует до четырёх кадров каталога. Остальные кадры каталога и все крупные `heroImage` ждут простого времени. У `<img>` каталога стоят `loading="lazy"` и `decoding="async"`. Ошибка загрузки возвращает кристалл. Карточка вне экрана не запускает вход, пока не попадёт в область просмотра. Прозрачность проверяется уменьшенным кадром: если альфа-канал пикселя меньше 250, это вырез и карточка парит. JPEG в эту проверку не входит и остаётся неподвижным.

`prefers-reduced-motion` выключает парение, наклон, тень, вход и переезд подложки.
