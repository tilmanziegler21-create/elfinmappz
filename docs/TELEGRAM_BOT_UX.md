# Текстовый бот ELFIN MARKET

Один процесс с Express API. Второй бот не создавался. Webhook не включался. Long polling стартует только при `TELEGRAM_POLLING=1` и принятом токене. В этой проверке polling не запускался.

## Меню

`/start` для покупателя — одно сообщение и inline-кнопки: Mini App, заказы, профиль, поддержка, информация. Команды `/shop`, `/orders`, `/profile`, `/help`, `/admin` работают без кнопок. Повторный `/start` не создаёт второго клиента. Telegram id хранится строкой.

Кнопка Mini App получает `web_app` только если `MINIAPP_PUBLIC_URL` начинается с `https://`. Локальный адрес не подставляется. Кнопка меню бота ставится тем же URL и только при запуске polling.

Язык по умолчанию русский. Если язык Telegram `de` или `en`, берётся он.

## Роли

Курьер определяется по `tg_id` активного курьера локальной книги. Пока нет `couriers_HH`, это не список Hamburg. Чужой заказ курьеру не показывается. «Выдал» и «Не выдал» идут в ту же функцию, что `POST /api/courier/orders/status`: повтор не меняет склад второй раз. Перед выдачей бот спрашивает подтверждение, перед отменой — причину.

`/admin` открывается только при `status=admin` или id из `ADMIN_TG_IDS`. Сводка не считает незакрытые заказы выручкой и не показывает токен.

## Поддержка

Обращение пишется в локальную базу. Если `SUPPORT_TG_ID` пуст, фиктивный контакт не показывается. Уведомление менеджеру уходит в очередь и при `TELEGRAM_TEST_MODE` не равном `0` отправляется только id из `TELEGRAM_TEST_IDS`. `sent` становится истинным только после ответа Telegram.

## Что не проверено в Telegram

`getMe` с токеном из внешнего файла окружения вернул `401 Unauthorized`. Сообщение `/start` живому аккаунту не отправлялось. Публичный HTTPS Mini App не задан.
