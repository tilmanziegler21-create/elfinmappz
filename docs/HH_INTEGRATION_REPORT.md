# Чтение таблицы Hamburg

Дата проверки: 26 октября 2026. Запись не выполнялась. Строки вкладок не читались: до чтения ячеек сервер останавливается, если нет полного набора HH.

## Доступ

Внешний файл окружения подхватился. Файл ключа на диске есть. `spreadsheets.get` со scope только на чтение вернул список вкладок. Секреты в ответ API и в этот отчёт не входят.

## Вкладки

Ожидались `products_HH`, `LiquidPrices_HH`, `couriers_HH`, `orders_HH`, `metrics_HH`. Ни одной нет.

Фактические названия: `products_MU`, `LiquidPrices_MU`, `couriers_MU`, `orders_MU`, `metrics_MU`.

Эти вкладки не подставлены как каталог Hamburg. `FFM` и `MU` в запросе города отвечают `400 INVALID_CITY`. `GET /api/catalog?city=HH` и `GET /api/couriers?city=HH` без демо-режима отвечают `503 SHEETS_HH_MISSING`, без товаров и без текста ключа.

Поля `sku`, `name`, `category`, `brand`, `price`, `stock`, `active` из `products_HH` не прочитаны, потому что вкладки нет. Картинки по-прежнему не привязаны к складским SKU: в `productMedia` поле sku пустое, чужой вкус не подставляется.

## Каталог Mini App

При `DEMO_CATALOG=1` витрина явно демо, цены «—». Без этого флага ошибка Google не заменяется товарами из `src/products.ts`. Живые заказы в таблицу не пишутся.
