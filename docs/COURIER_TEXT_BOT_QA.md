# Курьерский текстовый бот

Покупатель по-прежнему открывает Mini App. Курьер работает в том же боте, в обычном чате. Заказы читаются из `elfin_state` в PostgreSQL. Второго бота и второй базы нет. Запись в рабочий HG не включалась.

Короткого номера заказа в системе нет. На панели и кнопках показывается сохранённый `order_id`, например `ORD-MVTVNWPY`. Отдельный номер вида `#6570` не создавался.

Касса на панели — ожидаемая сумма открытых заказов этого дня (`pending`, `assigned`, `picked_up`). Выданные и отменённые в неё не входят. Дата считается по часовому поясу Europe/Berlin. Исходная `total_amount` при выдаче не меняется. Фактически полученная сумма, разница, курьер и время пишутся отдельно в `cash_received`, `cash_delta`, `cash_by`, `cash_at`.

Чужой или неактивный Telegram ID видит только «Доступ только для активных курьеров.» Кнопок заказа под этой фразой нет.
