# Готовность к production

Не готово.

Живая таблица Hamburg не подключена к витрине: нужных вкладок нет. Запись остатков, заказов и метрик в неё выключена. Telegram-бот на тестовом чате не прогонялся. Возраст по-прежнему только отметка 18+ в сессии браузера, этого недостаточно для запуска.

Можно оставить: локальные заказы на тестовой книге, демо-витрину с явной подписью, выключенные скидки и сравнение цен.

Включать `ENABLE_LIVE_ORDERS=1` и `SHEETS_READ_ONLY=0` только после копии таблицы, успешных списания и возврата на этой копии и отдельного решения владельца.
