# Повторные покупки

`ENABLE_LOYALTY` по умолчанию выключен. Проценты со скриншота WAKA не приняты как правила ELFIN.

На главной сетка из десяти шагов показывает число заказов со статусом `delivered` из `GET /api/order/history`. Отменённые и незавершённые не считаются. Денежная скидка, VIP-процент и обещание выгоды не выводятся.

`ENABLE_PRICE_MATCH` тоже выключен. Формы «Нашли дешевле?» в интерфейсе нет: без проверки рекламных ограничений для никотиновой продукции в Германии модуль не публикуется.
