# Оформление

Кнопка корзины открывает нижнюю панель. Закрытие панели не очищает поля и корзину.

Покупатель выбирает доставку или самовывоз, курьера из пришедшего списка, время из его слотов, имя, адрес или точку встречи и комментарий. Первый курьер сам не выбирается. Если списка нет, заказ не отправляется.

Оплата в панели одна: наличные при встрече. Карта в этот запрос не уходит.

«Подтвердить заказ» один раз проводит уже существующую цепочку:

1. `POST /api/order/create` с `Idempotency-Key`
2. `POST /api/order/confirm`
3. `POST /api/order/payment` с `paymentMethod: cash` и `bonusApplied: 0`

Повторное нажатие блокируется, пока запрос идёт. Корзина очищается только после ответа оплаты. Это локальная книга заказов, не склад Hamburg.
