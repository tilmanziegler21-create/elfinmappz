# Google Sheets

Секреты остаются вне репозитория. В `.env.example` только пустые имена переменных.

Рабочий доступ уже описан так: файл окружения и JSON-ключ лежат вне `elfin-market`, таблица открывается сервисному аккаунту. Для первого чтения рабочей таблицы достаточно роли Viewer. Editor нужен только копии, на которой разрешены тестовые записи.

Идентификатор таблицы — отрезок URL между `/d/` и `/edit`.

Ожидаемые вкладки: `products_HH`, `LiquidPrices_HH`, `couriers_HH`, `orders_HH`, `metrics_HH`. Пока их нет, сервер отвечает `SHEETS_HH_MISSING`. Вкладки FFM, HG и MU не подставляются.

`SHEETS_READ_ONLY` по умолчанию не равен `0`, `ENABLE_LIVE_ORDERS` не равен `1`. Новые вкладки сами не создаются.
