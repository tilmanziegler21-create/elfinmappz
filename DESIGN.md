## Форма

- Карточка: радиус 22px, белая заливка, тонкая светлая кромка, тень `0 12px 28px rgba(18, 58, 109, 0.05)`.
- Кнопка: высота 52px в основном действии, 36px у карточки товара.
- Нижняя панель: радиус 22px. Единственное размытие в интерфейсе — `backdrop-filter` на этой панели.
- Шрифты: Cormorant Garamond для названия, Manrope для интерфейса.

## Движение

Двигать только `transform` и `opacity`.

| Событие | Правило |
| --- | --- |
| Портрет | Постоянно: парение, свечение контура, сдвиг волос на 1–2px, редкое моргание |
| Фон | Постоянно: кристаллы на разной глубине, медленный перелив, дымка |
| Смена экрана | Сдвиг 18px и затухание, 0.42s, `cubic-bezier(0.22, 1, 0.36, 1)` |
| Нажатие | Пружина, scale 0.96, stiffness 560, damping 24 |
| Секция каталога | Stagger 0.08s |
| Карточка внутри секции | Stagger 0.04s |
| Поиск и чипы | Без входной анимации |
| Скелет | Только пульс прозрачности |
| `prefers-reduced-motion` | Анимации выключены |

На внутренних экранах у маленького портрета остаются только парение и свечение. Волосы и моргание выключены.

## Карточка товара

Адрес: `#product/{id}`. Id берётся из общего списка, отдельной копии товаров нет.

- Своя верхняя панель: назад, категория, счётчик корзины. Нижнее меню на этом экране скрыто.
- Сцена: декоративные слои двигаются через `transform` и `opacity`. Прозрачный WebP или PNG парит. JPEG и непрозрачное фото стоят. Нет кадра — фирменный кристалл.
- Парение: 5,5 с, ±10 px. Наклон: 11 с, ±3°. Тень в том же цикле, только `transform` и `opacity`. Вход знака: 700 мс.
- Объём открывается нижней панелью за 380 мс. Недоступный объём выбрать нельзя. Поиск фильтрует те же варианты товара.
- Скелет сцены — пульс прозрачности, затем появление через opacity и сдвиг.
- Переключение кадра — только opacity.
- Вариант выбирается пружинной подложкой. Недоступный объём нельзя выбрать.
- Количество от 1 до остатка выбранного объёма.
- Нижняя кнопка учитывает `safe-area-inset-bottom`. После добавления коротко показывает «Добавлено».
- Назад возвращает в каталог тем же сдвигом экрана.
- Нет товара и нет остатка — отдельные спокойные состояния, без новой темы.

## Корзина

Тот же общий список `productId:variantId`. Второй корзины нет. Zustand в проекте нет, поэтому список пишется в `localStorage` (`elfin-cart`) и при чтении сверяется с тестовыми товарами: неизвестные и пустые позиции выбрасываются, количество режется по остатку.

- Карточка: знак товара, название, объём, цена, количество, сумма строки, удаление.
- Количество от 1 до остатка. Ноль и минус не ставятся; снятие — отдельная кнопка.
- Удаление гаснет и сжимается до 0.92. «Вернуть» живёт 4 секунды и не создаёт вторую строку.
- Пустая корзина использует общий `EmptyState`. «Вернуть» есть только пока удаление ещё можно отменить.
- Нижняя панель без размытия: число позиций, сумма, итог, «К оформлению». Она в потоке под списком, нижнее меню остаётся свободным, снизу учитывается `safe-area`.
- «К оформлению» открывает тестовое оформление. Запрос к старому API не уходит, остатки не меняются.
- Вход строк — stagger 0.04s. Числа меняются через opacity и сдвиг на 6px. Кнопки — та же пружина, scale 0.96.

## Пустые состояния

Один компонент `EmptyState` и один кристалл `CrystalIllustration`. На экране бренд только `ELFIN MARKET`. Имя системы Ice Crystal остаётся в этом файле.

Загрузка, пусто и ошибка не подменяют друг друга. Пустой поиск не значит, что каталог пуст. Нет товара и нет остатка — тоже разные состояния.

| Вариант | Где |
| --- | --- |
| `cart` | Пустая корзина. Вторичная кнопка «Вернуть» только при живой отмене |
| `orders` | Экран заказов, если заказов ещё нет. Тот же кристалл стоит на загрузке и подтверждении оформления |
| `search` | Поиск ничего не нашёл. Поле поиска остаётся. Переход 220 мс |
| `catalog` | В каталоге нет позиций. «Обновить» снова показывает скелет, без ложного успеха |
| `favorites` | Раздел «Избранное», если отмеченных позиций нет |
| `promotions` | Экран предложений. Сейчас такого экрана нет, вариант готов |
| `unavailable` | Вариант есть, но остатка нет. Это не «позиция не найдена» |
| `connectionError` | Сеть или таблица не ответила. Это не «каталог пуст» |

Движение задано в `emptyMotion.ts` и не копируется по экранам.

| Шаг | Время |
| --- | --- |
| Кристалл | 450 мс, opacity и scale |
| Парение | 5 с, ±6 px и поворот 1.5°, только `transform` |
| Заголовок | 350 мс, задержка 100 мс |
| Описание | 350 мс, задержка 170 мс |
| Кнопка | 400 мс, задержка 240 мс |
| Нажатие | Пружина, scale 0.97 |

Вход играется один раз. Свечение — готовый слой, меняется только opacity. `prefers-reduced-motion` выключает парение и вход. Поиск использует тот же набор, но ужимает вход до 220 мс.

## Оформление

Кнопка «Оформить заказ» подряд вызывает `create`, `confirm` и `payment`. Корзина очищается только после успеха оплаты, затем открывается история.

- Состав и итог берутся из той же корзины.
- Получение: доставка или самовывоз. Курьер выбирается из активных. Время — слоты его интервала. Если у курьера задана точка самовывоза, поле только для чтения.
- Адрес или точка встречи, комментарий, оплата «наличные при встрече».
- Строка про бонусы до 50% только объясняет будущий лимит. Списания нет.
- Загрузка и подтверждение используют кристалл заказов: opacity и парение, без blur и WebGL.
- Карточка курьера и диалог «Выдал» / «Не выдал» в том же льду. Покупатель выдачу не подтверждает.
